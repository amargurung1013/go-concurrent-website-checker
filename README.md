# Concurrent Website Checker

A website status checker built with Go to explore concurrency,
goroutines, and channels.

## Features

- Checks HTTP status codes
- Measures response time
- Checks multiple websites concurrently
- Uses goroutines to execute requests concurrently
- Uses channels to collect website results

## Technologies

- Go
- net/http
- Goroutines
- Channels

## Run

Clone the repository and navigate to the project directory.

Run the program:

```bash
go run main.go
```
